# Bancosys 🏦

Este es un sistema de gestión bancaria desarrollado como parte de mi formación en Ingeniería en Sistemas. El proyecto se enfoca en la lógica de transacciones y manejo seguro de datos.

### 🚀 Tecnologías utilizadas:
* **Lenguaje:** PHP
* **Base de Datos:** MySQL
* **Entorno:** Linux Mint / Stack LAMP

### 🛠️ Características:
* Gestión de usuarios y cuentas.
* Registro de movimientos y transacciones.
* Interfaz lógica de backend.
